# The Excuse That Almost Works

One line a gamer texts the boss to get out of work during GTA 6 launch
week — at most 20 words, plain text, sent in a hurry:

> sorry can't come in, my controller charger fried the power strip and tripped the whole flat, electrician's at noon

The angle is a small, boring, specific household mishap with a gaming
detail tucked inside it — a controller charger killing the power —
instead of any of the classics (dead grandmother, flat tyre, sudden
fever). Nothing in it confesses to playing GTA; the manager is left
with a flat with no electricity and an electrician due at noon.

`main.py` writes that single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). It guards the line itself: 19 words,
95 characters, inside the 1–20 word and 1–140 character limits. No
network, no randomness, standard library only — every run writes the
same line.
